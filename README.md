# PixelDojo

**Train your design judgment.**

PixelDojo is a gamified learning product for training design judgment through fast visual decisions and learning the principles behind each decision.

## Core loop

Observe → Decide → Reason when valuable → Learn → Progress → Next

## MVP

- Next.js + React + TypeScript
- English and Spanish from day one
- 10 static starter battles
- No account required
- No Supabase until the battle model is stable

## Initial skills

- Visual hierarchy
- Spacing / Gestalt proximity
- Typography
- Forms
- Checkout
- Accessibility

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Product principle

Nothing enters the MVP unless it improves the loop:

**see → choose → understand → continue**
